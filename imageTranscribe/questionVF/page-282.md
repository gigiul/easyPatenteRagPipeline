INCIDENTI E ASSICURAZIONE
CAUSE DI INCIDENTI
Cause di compromissione di idoneità alla guida
Blocco: 32003
DOMANDE VERE
1. L'idoneità alla guida può essere compromessa se si fa uso di alcuni farmaci sedativi
2. L'idoneità alla guida può essere compromessa se si fa uso di farmaci antidepressivi
3. L'idoneità alla guida può essere compromessa se si fa uso di allucinogeni (LSD, ecstacy, ecc.)
4. L'idoneità alla guida può essere compromessa se si fa uso di bevande alcoliche
DOMANDE FALSE
1. L'idoneità alla guida può essere compromessa se si fa uso di caffè amaro
2. L'idoneità alla guida può essere compromessa se si fa uso di bevande gassate
3. L'idoneità alla guida può essere compromessa se si fa uso di integratori di sali minerali
4. L'idoneità alla guida può essere compromessa se si fa uso di integratori alimentari
Cause di compromissione di idoneità alla guida
Blocco: 32004
DOMANDE VERE
1. L'assunzione di hashish o di marijuana può compromettere la facoltà di guida
2. L'assunzione di eroina o di cocaina può compromettere la facoltà di guida
3. Nei farmaci sedativi sono presenti alcune sostanze che possono compromettere la facoltà di guida
DOMANDE FALSE
1. L'assunzione di LSD o l'anfetamina non compromette la facoltà di guida
2. L'assunzione di hashish o di marijuana non compromette la facoltà di guida
Effetti dell'alimentazione sull'idoneità della guida
Blocco: 32005
DOMANDE VERE
1. Un'alimentazione pesante ed eccessiva è sconsigliata per chi deve guidare
2. L'alimentazione con cibi di difficile digestione può provocare una diminuzione dell'attenzione e un aumento dei tempi di reazione
DOMANDE FALSE
1. L'assunzione di bevande superalcoliche, durante un pasto abbondante non compromette la facoltà di guida
Uso responsabile della strada
Blocco: 11034
DOMANDE VERE
1. Bisogna lasciare liberi gli incroci in caso di traffico intenso
2. Bisogna lasciare liberi i passaggi a livello e i binari del tram anche in caso di traffico intenso
3. Bisogna lasciare liberi gli attraversamenti pedonali e quelli ciclabili in caso di formazione di code di veicoli
4. Bisogna lasciare libere le immissioni stradali (incroci, confluenze, ingressi dei parcheggi, ecc.) anche in caso di traffico intenso
DOMANDE FALSE
1. Bisogna lasciare liberi solo gli incroci regolati da semaforo in caso di formazione di code di veicoli
2. Bisogna lasciare liberi i cavalcavia in caso di traffico intenso
3. Bisogna lasciare libere le gallerie in caso di formazione di code di veicoli
4. Bisogna lasciare liberi gli ingressi delle abitazioni private in caso di formazione di code di veicoli
5. Bisogna lasciare liberi i sottovia in caso di traffico intenso
